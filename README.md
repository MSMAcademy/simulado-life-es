# MSM Academy — Simulador de Life Insurance en Español

Sitio web estático con 94 preguntas extraídas de la apostila proporcionada. Inspirado en la organización de https://msmacademy.github.io/simuladoen/ (sin reutilizar código o imágenes de ese sitio).

## Funciones
- 25, 50 o 94 preguntas; modo Estudio (corrección inmediata) o Examen (temporizador y corrección final).
- Notas por intento, historial guardado localmente, preguntas guardadas, enfoque en las más falladas y revisión de incorrectas.
- Resultados imprimibles. Todo funciona en el navegador; no recopila datos de usuarios ni usa servidor.

## Publicación en GitHub Pages
1. Crea un repositorio público `simulado-life-es`.
2. Sube **el contenido** de esta carpeta (`index.html`, `app.js`, `style.css`, `questions.json`). No subas solo el ZIP.
3. Ve a Settings > Pages > Build and deployment > Deploy from a branch; selecciona `main` y `/(root)`.
4. Abre `https://TU-USUARIO.github.io/simulado-life-es/` después de completar la publicación.
